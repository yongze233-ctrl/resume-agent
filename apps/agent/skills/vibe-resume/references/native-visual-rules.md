# Scoped visual rules derived from Vibe Resume

Source: ../upstream/UPSTREAM-SKILL.md, “Layout Hard Constraints”, “Density and White Space Tuning”, “Asset Handling”, and “Export and QA”. The full source and original license are retained. User confirmed commercial permission.

- Plan a photograph slot before text composition. Preserve the original photograph, color and face; keep nearby text clear of its bounds.
- A spacious page is allowed. Use whitespace to expose the grouping. Do not invent filler, duplicate columns or add weak claims merely to fill paper.
- Repeated visual roles share size, weight and spacing. Use stable style tokens instead of many unrelated font sizes.
- Start with readable body type, at least 9pt. Use actual Chinese text to tune leading, normally starting around 1.35–1.5. Re-check the rendered page after any adjustment.
- If content is dense, fix abnormal gaps and column geometry first. Never use letter-spacing or tiny fixed text boxes as density controls.
- If content is light, increase type/leading and the rhythm between groups before creating large empty bands.
- Distinguish section spacing, entry spacing and within-entry spacing. Values are calibrated for the actual page, not copied blindly from HTML.
- Check the actual PDF page size, embedded fonts, selectable text, portrait, overlap, clipping and stable alignment. Keep a last good version before rebuilding.

For this integration all source text and section/entry order are fixed. The complete upstream raw→selected-resume workflow is available but outside this visual-only task.
