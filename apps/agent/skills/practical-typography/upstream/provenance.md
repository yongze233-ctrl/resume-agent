# Rule provenance registry

This file is the source of truth for normative rule clusters in the typography skill. Classifications are:

- `PT`: paraphrased from Matthew Butterick's *Practical Typography*;
- `DEVIATION`: a deliberate project-authored heuristic or workflow choice;
- `CURRENT`: a current accessibility, internationalization, platform, semantic, or legal requirement from another authority.

`Scope` describes where the rule applies. `Evaluations` point to scenario IDs in `../../evals/scenarios.json`. Source pages and external standards were verified on **2026-08-22** unless an entry says otherwise. The registry stores paraphrases and page identities, not source prose.

## Resolved legacy claims

The baseline revision was `41559fe7ee3c27c4fc46a6feda29ad7898c7b4c6`. Every previously unclassified normative cluster was mapped above or retired:

- `45–90ch` as literal character count → replaced by actual-character verification (`TYPE-001`, `WEB-002`).
- Ligatures on by default → replaced by collision-dependent prose guidance and literal code protection (`FONT-004`).
- Fixed heading ratio `1.6 / 1.25 / 1.0` and exact supporting-element ratios → retired as unsupported source precision (`TYPE-004`, `MEDIA-002`, `MEDIA-005`).
- Unconditional quote, `(c)`, dash, ellipsis, and whitespace conversion → gated by content type and semantic intent (`AUDIT-002`, `COMP-001..005`).
- “Full” system-font list → corrected to a dated shortlist (`FONT-001`).
- Unconditional “Inter passes” and feature checklists attributed to the source → replaced with a project-authored, context-dependent validation rubric (`FONT-002`).
- Fixed slide pixel ranges and exact callout, code, caption, navigation, table, and rule ratios → replaced by medium calibration or explicitly scoped starting points.
