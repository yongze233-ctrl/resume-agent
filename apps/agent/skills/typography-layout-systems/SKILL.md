# Typography layout systems — OpenPencil integration

Read `upstream/UPSTREAM-SKILL.md` for the full installed composition method. Adapt its fixed-page guidance to A4 native layers.

Use the supplied content groups and order as fixed input; do not decide which experience is more important or rewrite its evidence. Choose one structural system before drawing. An axial or grid structure usually fits a resume; avoid theatrical poster structures that obscure reading. Use asymmetry through intentional proportions, not arbitrary offsets.

Give the portrait a deliberate slot related to the name and contact block. Align entry titles, body starts and dates to a small set of axes. Let empty space separate groups. A line or color field needs an organizational purpose. Keep supporting text subordinate with consistent style rather than scattered manual adjustments.

Choose the composition independently of the old resume's default theme color. Native text stays editable. Use `visual.text` and `visual.stack` for stable text geometry, then inspect actual bounds and review the exported PDF.
